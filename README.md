# Vita — твоя жизнь в точках

Генератор обоев для айфона: месяц / год / жизнь в виде сетки точек.
Каждый день сервер закрашивает новую точку — обои обновляются сами через Ярлыки iOS.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8787
```

Открыть http://localhost:8787

## Как устроено

- `static/` — одна страница: настройка + живое превью на канвасе + скачивание PNG
- `app/render.py` — тот же рендер на Pillow для серверных картинок
- `POST /api/link` — сохраняет настройки, возвращает персональную ссылку + ссылку на установку
- `GET /w/{code}.png` — всегда свежие обои (сегодняшняя точка закрашена) — её тянет ярлык iOS раз в день; счётчик скачиваний пишется в БД
- `GET /s/{code}` — страница установки: 3 шага (ярлык → автоматизация → проверка).
  Тем, кто уже пользовался (обои тянулись) или у кого доступ истёк, показывает блок
  «вторая неделя за отзыв»
- `POST /api/review` — приём отзыва: разовое авто-продление на 7 дней (`review_at` не даёт
  получить дважды), текст пишется в `reviews` и виден в админке (UGC для рилсов)
- `/me` — анонимный личный кабинет Vita ID: новые цели, автообои, публикации и настройки
  виджета привязываются к приватному коду без почты и пароля
- `/admin?token=…` позволяет выдать доступ по `@тегу`: пустой срок означает
  бессрочно. Право хранится у профиля и действует на уже созданные и будущие
  автообои. Зарезервированный `@vit` назначается только админом и всегда имеет
  бессрочный developer-доступ; проверки владения чужими данными он не обходит.
- `PATCH /api/goal/{code}` — редактирование своей цели; `/api/feed-post` — публикация своей
  цели или обоев с описанием и необязательным фото
- **Vita Импульс** в iOS-приложении — пошаговое создание напоминаний с папками,
  минимальным шагом, дедлайном и отдельным предупреждением. На iOS 26 важный импульс
  можно включить как системный будильник; тексты остаются на устройстве.
- `POST /api/access` — статус доступа по Vita ID: куплен навсегда, идёт проба или всё замерло
- `POST /api/buy` → `/buy` → Робокасса → `/pay/result` — одна вечная покупка (см. «Оплата»)
- `GET /healthz` — живость для мониторинга и docker healthcheck
- `data/vita.db` — SQLite, создаётся сама (в git не входит).
  Каталог данных можно переопределить `VITA_DATA=/path` — для dev/тестов без риска для боевой БД

## Мастер-ярлык «Vita» (создаётся один раз на iPhone)

1. Приложение «Команды» → «+» → назвать ярлык **Vita**
2. Добавить действия по порядку:
   - **Текст** — вставить любую ссылку вида `https://…/w/код.png` (заглушка)
   - **Получить содержимое URL** — вход: Текст
   - **Установить обои** — вход: Содержимое URL; выключить «Показывать предпросмотр»
3. Поделиться → включить **Import Question** для поля «Текст»
   (вопрос: «Вставь свою ссылку Vita») → **Скопировать ссылку iCloud**
4. Вставить ссылку в `SHORTCUT_ICLOUD_URL` в `app/main.py` — кнопка
   «Добавить ярлык» на странице установки оживёт сама.

## Деплой (сервер с yoy: один Caddy на двоих)

```bash
# на сервере, рядом с ~/yoy
git clone https://github.com/novohron0/vita.git ~/vita
cd ~/vita
cp .env.example .env && nano .env   # ADMIN_TOKEN=случайная строка
docker compose up -d --build        # поднимет vita на 127.0.0.1:8788

# yoy-Caddy уже знает про Vita (блок {$VITA_DOMAIN} в Caddyfile):
cd ~/yoy && git pull && docker compose up -d
# домен по умолчанию: vita.138-124-51-182.sslip.io (менять — VITA_DOMAIN в ~/yoy/.env)
```

Обновление: `cd ~/vita && git pull && docker compose up -d --build`.

### Доступность и HTTPS

TLS выпускает **Caddy** (`~/yoy`, контейнер `yoy-caddy-1`) — certbot вручную не нужен.
Сертификат продлевается автоматически.

**DNS у регистратора домена** (обязательно для `www`):

| Тип | Имя | Значение |
|-----|-----|----------|
| A | `@` | IP сервера (138.124.51.182) |
| A | `www` | тот же IP |

После добавления `www` Caddy сам получит сертификат и редиректит на `https://vitadots.ru`.

Проверка с Mac:
```bash
./scripts/check-site.sh
```

## Оплата — одна вечная покупка

Подписки нет: 590 ₽ один раз, доступ бессрочный и привязан к профилю (Vita ID).
Первые 7 дней бесплатны и даются всем без анкет.

- страница покупки `/buy`, оферта `/offer`, результат `/pay/success` и `/pay/fail`
- платежи проводит **Робокасса** (POST-форма на `auth.robokassa.ru`), чеки НПД
  через «Робочеки СМЗ» — самозанятому бесплатно, разрешение выдаётся в «Мой налог»
- доступ открывает уведомление на **ResultURL** `https://vitadots.ru/pay/result`
  (подпись Пароль#2, ответ `OK{InvId}`); повторные уведомления безопасны
- в ЛК Робокассы указать: Result `https://vitadots.ru/pay/result` (метод POST),
  Success `https://vitadots.ru/pay/success`, Fail `https://vitadots.ru/pay/fail`
- переменные `.env` на сервере:
  `ROBOKASSA_LOGIN`, `ROBOKASSA_PASS1`, `ROBOKASSA_PASS2`, `ROBOKASSA_TEST=0`,
  `ROBOKASSA_SNO` (пусто, если чек формирует сама Робокасса), `VITA_PRICE=590`,
  `SELLER_NAME`, `SELLER_INN`, `SUPPORT_CONTACT` — реквизиты подставляются в оферту
- без ключей оплата выключена: сайт честно пишет «оплата подключается», проба работает
- проверка: `python3 tests/test_billing.py` — подпись, чужая подпись, заниженная сумма,
  повтор уведомления, запрет второй покупки

## Письма с кодом на смену пароля

Забыл пароль → четырёхзначный код уходит **письмом на ту же почту**, которой
человек входит. Телеграм остался запасным путём: если письмо не отправилось,
а телеграм привязан — код идёт туда.

- шлём через DashaMail (бесплатный тариф — 2000 писем в месяц; транзакционную
  отправку на нём включает техподдержка по просьбе). Хост именно
  `smtps.dashasender.ru:2525` — у `smtp.dashamail.ru` сертификат на другое имя.
  SendPulse и другие зарубежные сервисы отпали: регистрация без России
- **хостинг Aeza режет порты 25, 465 и 587** — наружу открыт только 2525,
  поэтому `SMTP_PORT=2525` и `starttls`; обычная почта Яндекса/Mail.ru
  с этого сервера не отправится
- переменные `.env` на сервере: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`,
  `SMTP_PASS`, `SMTP_FROM` (адрес на подтверждённом домене), `SMTP_FROM_NAME`
- в DNS домена нужны записи SPF, DKIM и DMARC, которые выдаёт SendPulse —
  без них письма падают в спам
- без ключей письма выключены сами: ручка отвечает как раньше и зовёт в телеграм
- когда письма включены, `/api/auth/forgot` отвечает **одинаково** на любую
  почту, есть такая у нас или нет: иначе формой можно перебрать наших людей.
  Повторное письмо не раньше чем через минуту — чужой ящик не завалить
- проверка: `python3 tests/test_auth.py` — код в письме и в теме, повтор без
  второго письма, молчание на чужую почту, запасной путь через телеграм

## Нагрузка и сохранность

- схема и миграции выполняются один раз на процесс, база в WAL, `busy_timeout` 20 с
- готовые PNG обоев лежат в `data/wpcache` с ключом по дате: за сутки картинка
  рисуется один раз, вчерашние чистятся сами
- дорогие POST (`/api/link`, `/api/buy`, загрузки файлов) ограничены по IP в памяти процесса
- бэкап базы: `scripts/backup.sh` на сервере, в cron — например
  `5 4 * * * cd /root/vita && ./scripts/backup.sh >> /var/log/vita-backup.log 2>&1`

## Воронка (цель продукта)

Reels → сайт → обои за 30 секунд → 7 дней бесплатно → 590 ₽ один раз навсегда.
Максимальный минимализм, ноль регистраций.
